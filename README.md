# Creative Rizz — Rizwan Khan Portfolio

A custom Next.js portfolio for Rizwan Khan, rebuilt from the existing portfolio content and visual assets with an original interaction-led design direction.

## Stack
- Next.js App Router
- React
- Framer Motion
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

The project currently references public image assets from the original portfolio repository so the text/code can be versioned cleanly without duplicating binary files during this first push.
